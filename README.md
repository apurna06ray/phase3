# 🧠 Interactive Quiz Master – Flavortown Edition 🌭

Step into **Flavortown of knowledge**! 🌟  
This is an **interactive quiz app** where users answer multiple-choice questions, get instant feedback, and track their score while having fun.  

---

## 🍔 What the project does
- Gamified quiz experience with multiple-choice questions  
- Instant feedback for correct/wrong answers  
- Real-time score tracking  
- Smooth UI with hover animations  

---

**Apurna Ray / Flavortown Dev Team** – focused on creating a **lightweight, fun, and engaging quiz experience** using HTML, CSS, and JavaScript.
